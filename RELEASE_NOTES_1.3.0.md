# Coconut Chunks 1.3.0

Coconut Chunks is a fully offline Android app for collecting and reviewing German chunks with your own example sentences.

## Highlights
- Save German chunks with up to three personal examples and notes.
- Organize chunks into groups.
- Search across chunks, examples, and notes.
- Review with recall-first cards that hide examples until reveal.
- Mark chunks as Review, Special, or Mastered.
- Use weighted review so Special chunks appear more often while Mastered chunks still return occasionally.
- Review an entire group exactly once in random order.
- Use configurable Daily Review targets.
- Undo review-status actions.
- Export/import JSON backups and export CSV.
- View a calm, non-gamified overview of your collection.

## Privacy
- No account
- No server
- No ads
- No analytics
- No trackers
- No INTERNET permission

All app data stays on the device unless you explicitly export it.
